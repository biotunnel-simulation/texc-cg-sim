# Ribosome Exit Tunnel Extraction and MD Simulation Workflow 

This repository contains the supplementary code for the paper [Prokaryotic-like ribosome exit tunnels in eukaryotic protists: structural origins and functional consequences](#url_to_be_added).

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24407554.svg)](https://doi.org/10.5281/zenodo.24407554)

## Dependencies

- Python 3.9
- [LAMMPS version 29 Aug 2024](https://www.lammps.org/)
- [MOLE2](https://webchem.ncbr.muni.cz/Platform/App/Mole)
- [PyMOL 2.6](https://www.pymol.org/)
- [Muscle v5](https://drive5.com/muscle5)  
  
## Usage

This project involves an automated workflow for tunnel extraction and downstream geometric analysis using Python scripts, as well as coarse-grained molecular dynamics (MD) simulations performed using LAMMPS.

- E. coli PDB structure 6WD4 is used as an illustrative example.
  
### Tunnel Extraction & Downstream Geometric Analysis

First, generate a truncated ribosome structure that retains the atoms surrounding the ribosome exit tunnel within an approximately 80 Å radius to reduce computational costs

```
python3 Truncated_6WD4.py
```

Second, execute `mole2.exe` to perform tunnel searching and extract potential tunnel structures, both with and without specifying the exit-port coordinates. The exit-port coordinates correspond to those of conserved nucleotides in uL23 or eL39 near the tunnel exit, identified through sequence alignment.

```
./mole_Tunnel
```

Finally, execute `Tunnel_Finalization.py` in Visual Studio to identify the actual exit tunnel for each ribosome, and generate 2D radial plots based on the tunnel centerline coordinates and their corresponding radii.

### MD Simulations

#### Polypeptide Elongation
Tunnel data files for elongation studies compatible with LAMMPS simulations can be generated by following the [Nascent Peptide Exit Tunnel (NPET) Coarse Grained simulation protocol](https://github.com/bioshape-analysis/npet-cg-sim.git) and the paper [Advanced coarse-grained model of the ribosome exit tunnel for fast simulation of the nascent polypeptide chain dynamics](https://pubmed.ncbi.nlm.nih.gov/41194472/).

After determining the position of the newly added bead and the direction of chain elongation, perform the simulations to generate elongation trajectories as follows:
```
./mesh_trans
```
#### PTC Accessibility
Before generating the tunnel data files for ligand diffusion studies using the same workflow, the tunnel mesh structure (*.stl*) must first be modified by cutting open the PTC side in Autodesk Fusion.

To reduce computational costs, adjust the number of tunnel wall beads by removing overlapping beads and generate a new tunnel data file as follows:
```
./reduce_beads
```

Then, use Python to generate the coordinates of a five-bead ring positioned positioned near the tunnel exit port and create the corresponding data file, `data.6WD4_diff_1`. 

Run a preliminary simulation to sample different initial positions along the diffusion pathway. These sampled positions can then be used as alternative starting configurations for subsequent simulations:
```
lmp_serial < in.diffusion_6WD4
```

Finally, perform more simulations to generate ligand diffusion trajectories from the tunnel exit port toward the PTC as follows:
```
./mesh_diffuse
```
