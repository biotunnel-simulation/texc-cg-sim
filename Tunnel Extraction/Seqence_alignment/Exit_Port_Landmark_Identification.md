The landmarks at the tunnel exit port were identified through sequence alignment of the ribosomal proteins uL23 for prokaryotes and eL39 for eukaryotes using muscle5.1. 
For each protein, the residue with the highest conservation score that was also physically closest to the exit port was selected as the landmark. 
Its spatial coordinates were then determined using PyMOL, with the residue's proximity to the exit port verified through visual inspection.

Two examples of sequence alignments for uL23 and eL39 are provided using only representative species.
